# Mastermind Mission Control

## What This Is

Sanitized testing build of Get Sorted / Golden Claw, kept as a project wrapper around the active `mission-control/` Next.js app plus supporting agents, docker assets, and local tooling.

## Key Files

- `README.md` — build purpose, tiering, and setup notes
- `mission-control/` — active Next.js dashboard code
- `agents/` — background agents and support logic for this test build
- `docker/` — local container and deployment helpers
- `package.json` — project-level scripts

## Status

Active testing surface. The nested `mission-control/` directory is the main development target; the top-level project folder provides sanitized-build framing and support assets.
